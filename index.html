Help

Manifest Builder writes the manifest.json that every Bedrock pack needs. Fill the steps in order and download the file at the end.

The steps

  1. Pack type: behavior pack, resource pack, both as one add-on, skin pack or world template. It decides which fields the next steps show. Format 2 is the safe choice; format 3 writes versions as text.
  2. Identity: the name and description players see, the pack UUID (already filled, keep it after release) and the pack and minimum game versions.
  3. Contents: one module per kind of content. A behavior pack with scripts has a data module and a script module, each with its own UUID.
  4. Extras: dependencies on other packs or script modules, capabilities, authors and license. All optional.
  5. Review: the final JSON. Copy it or download it. Download pack gives a ready .mcpack (.mcaddon for an add-on): open the file and Minecraft imports it. Pack + source (.zip) adds the pack folder next to it.

Problems

Mistakes show live in the Problems list, on the step tabs and at the bottom. Click one to jump to its field. Many have a fix button, like New UUID.

Behavior + resource

An add-on is two packs. Use the BP / RP switch to edit each one. Authors, license and website are shared by both while "Same for both packs" is on.

Good to know

  • Your work is saved in this browser. Start over is in About.
  • Import (top right) loads an existing manifest.json to edit it.
  • The ? next to each field explains it.
